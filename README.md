### 🏥 Nankana Home Care Ecosystem
I am currently developing a unified, three-tier healthcare management platform tailored for local operations in Nankana Sahib, Punjab. The ecosystem is split cleanly into three decoupled architectures:

* **🌐 [Nankana Home Care Web Brochure](https://github.com/EllifeDash/nankana-home-care)**
    * *The Public Face:* A localized marketing and booking landing page designed for patient onboarding and service discovery.
* **📱 [MediAssist Pro PWA](https://github.com/EllifeDash/mediassist-pro)**
    * *The Field Assistant App:* An offline-first, Progressive Web App featuring Urdu localization used by medical assistants to digitize candidate records on the move.
* **🔑 [NHC Admin Portal](https://github.com/EllifeDash/nhc-admin-portal)**
    * *The Control Center:* A private administrative panel utilizing high-privilege access to manage team directories, trigger onboardings, and dispatch instant magic-login links.

---
*Stack: Vanilla JS (ES Modules) • Supabase Backend API • PWA Architecture • GitHub Pages*
